# 农场随心

八个独立 Mod，共用原生菜单最右侧的芽苗标签。无需额外核心 Mod，可以分别安装、更新和停用。

| Mod | 中文名 | 功能 |
| --- | --- | --- |
| TravelEase | 随心往返 | 回家、固定地点传送、返回上个位置、骑乘时人马同行、一键回床睡觉 |
| GardenEase | 田园巧整 | 作物、牧草、树木、道路与设施的单件搬移/交换、批量框选平移、一键牧草疏植、范围预览与整批撤销 |
| FishingEase | 从容钓鱼 | 绿色条加长、失误宽限、减少扣减、触底缓冲 |
| StorageEase | 随取随用 | 多人同箱操作、快捷开箱、首件物品图标与紧凑标签切换、远程箱子、物品搜索、制作自动取材、逐箱功能开关与舒适/随行模式 |
| SignEase | 一目了然 | 箱子正后方物品牌自动显示首件物品图标，空箱清空，原生多人同步 |
| RidingEase | 悠然骑行 | 关闭骑马的马蹄震动，保留马蹄声和其他震动，菜单可恢复 |
| HorseEase | 闻哨而来 | 菜单或 F10 一键呼唤自己的马，无需马笛，沿用原版室外限制与多人同步 |
| TimeEase | 适时而归 | 每日现实时间额度、提前提醒、跨重启计时；单人保存后休息；远程联机/纯本地分屏保存后退出预览 |

## 统一入口

L3 / F7 直达「农场随心」，也可以在原生菜单点击最右侧芽苗标签。LT / RT 保留原生标签切换及首尾循环。

主面板只显示已安装的功能。新增的「牧草疏植」属于田园巧整，点击直接执行并进入整理画面，可用 X / Z 撤销。选择「田园巧整」直接进入整理模式，选择「随取随用」直接打开上次使用的箱子，其他功能进入对应分类后操作；B / Esc 返回上一级，主面板再返回则关闭菜单。
方向键、十字键和左摇杆支持长按连续选择。整理中按返回先取消选中；没有选中时直接返回「农场随心」主菜单。
手柄 Y / 键盘 B 切换单件与批量整理；框选两个角后整组平移，一次最多 256 格。允许选区与原位重叠，遇到选区外占用等冲突时整批不执行；X / Z 一步撤销整批。
整理时镜头在中央区域保持固定，仅靠近边缘时平滑跟随；上下操作面板会计入跟随边界。
「田园巧整」支持搬移带物品的箱子、正在加工的普通机器、告示牌和篝火，保留内部物品、加工进度、牌面图案/文字及篝火点燃状态。选中洒水器或稻草人时显示拟放置位置的覆盖范围；道路与上方物体分开整理。
普通牧草和蓝色牧草支持单件搬移、互换及批量整理，允许原位置和目标位置站着农场动物，保留草种和剩余草量；框选可一起搬走牧草与上方围栏，撤销不会补回已被动物吃掉的草。
「牧草疏植」无需配置，自动将全农场可移动牧草按棋盘式错位分散，优先鸡舍、畜棚等动物建筑门外可达空地，多栋建筑轮流分配；不参考动物当前的位置或数量。围栏/设施下的草不动，空间不足的草留在原处，不增加草量或修改自然生长规则。
树木在树干底部选中，保留生长阶段、树龄和果实；采集器随树整体搬移并保留加工进度。支持树木之间交换与撤销，果树检查间距和幼树周围空位。
安装新版「随取随用」后，短按 L3 松开打开菜单，长按约 0.5 秒直接打开上次的箱子；F9 同样快捷开箱。骑马时也可使用这两个入口，等待、换箱和返回菜单均不要求下马；上下马动画期间暂停。首次使用或箱子不可访问时显示列表。从快捷入口退出回到游戏，从统一菜单进入则返回统一菜单。
手动或远程打开普通箱子后，顶部显示箱子标签和「全部箱子」入口；在箱子中按 L3 / F7 可搜索和管理全部箱子。LT / RT、PageUp / PageDown 或点击标签切换箱子，首尾循环；有手持物品时需先放下。
「随取随用」默认让所有玩家在各地打开所有支持的箱子，制作自动取材；舒适模式限制在农场/农舍使用，烹饪取材默认关闭。箱内物品不自动参与送礼、献祭、出售或任务。
「一目了然」默认自动开启：把木牌、石牌或金色物品牌放在箱子正上方一格，自动显示箱内首件物品；空箱清空图标，移开后保留最后图案。统一菜单可开关，只有房主执行更新，其他玩家无需安装也可看见。
钓鱼页面可选择关闭、轻度、默认和大幅辅助，标记当前预设，选择后自动保存。
「悠然骑行」默认关闭骑马时马蹄落地的手柄震动，保留马蹄声和其他震动；统一菜单可恢复。本机分屏共用开关。

「闻哨而来」在统一菜单首页直接呼唤自己的马，也可在游戏中按 F10。无需携带马笛，但需要已拥有并认领命名的马；沿用原版室外、落脚空间和坐骑占用限制，不生成新马。手柄可从菜单直接选择，或自行配置专用按键。

统一菜单首页和「随心往返」页面新增「一键睡觉」：回到自己的住宅床位后，进入原版睡觉、结算与存档流程。多人时只让当前玩家进入原版等待，可取消，不强制其他玩家结束一天。住宅里没有床时拒绝执行，入屋触发事件或床位变化时取消自动睡觉。

手柄 View / Back 短按松开打开任务日志，长按 1.2 秒一键睡觉，显示进度并可中途松开取消；菜单、对话及过场中保留原作用。

「随心往返 → 选择目的地」分为农场周边、小镇、野外、远方四组，共 16 个落点。除原有地点外，新增旅行货车附近、铁匠铺 / 博物馆、法师塔门口、铁路 / 温泉、采石场、鱼店码头、秘密森林、沙漠和姜岛码头。铁路与远方等地点按原版进度开放，未解锁时显示原因；姜岛要求当前玩家先正常登岛一次。解锁后均免费传送，建筑落点在门外，仍遵守营业时间；矿洞落点为入口大厅，电梯仍使用已解锁楼层。

快捷回家仍是长按 R3 / F8 0.7 秒，松开取消。只有安装「随心往返」才占用这个快捷键。骑马时回家、选择目的地和返回上个位置都带上当前坐骑，并按马的占地检查安全落点；可直接在马上用 L3 / F7 打开菜单。上下马动画期间暂停传送，一键睡觉仍需先下马。

共享菜单已修复骑乘时长按开箱的计时检查。升级时请同步替换同机已安装的各系列 Mod，保证当前菜单提供者使用修复版。

## 多人游戏

统一菜单、传送、整理及钓鱼已适配联机和本地分屏。随心往返 1.4.1、田园巧整 1.9.1、从容钓鱼 0.3.3、随取随用 1.5.2、一目了然 0.1.1、悠然骑行 0.1.1、闻哨而来 0.1.0。

- 传送与钓鱼只需使用者安装；回家前往自己的住宅。分屏传送记录、长按状态和当前钓鱼设置分别保存。
- 农场整理需要房主与参与整理者安装相同版本的田园巧整。支持多人同时整理不同格子，各自撤销；选中的格子暂时保留给本人，同格提交由房主检查冲突。别人后来整理过的格子会使相关旧撤销失效。世界时间继续流逝，箱子仍检查使用状态并加锁。
- 远程仓储需要房主和使用者安装相同版本 StorageEase；所有支持的箱子统一对全部玩家开放，以箱内首件物品图标和名称自动识别，远程/取材开关由所有玩家共同管理；支持多人同时查看同箱，房主排队协调短时原生锁内的取放与制作；浏览不占锁，箱子搬动后旧界面关闭。
- 自动告示牌只需房主安装 SignEase，使用原版牌面网络字段同步；客户端不用安装。只安装 SignEase 也可以工作。
- 呼唤坐骑只需使用者安装 HorseEase，房主通过原版马笛网络事件完成召唤，不要求房主安装；多人只召唤自己的马。本机分屏的请求间隔分别计时。
- 骑马震动开关只需使用者安装 RidingEase，不要求房主安装；本机分屏共用开关，其他玩家的电脑不受影响。
- 多人实机和分屏手感尚未验证，本次仅完成源码适配、编译及安装核对。

## 适时而归

TimeEase 0.1.6 的单人保存后休息流程已在 Mac 人工验证，用户确认现有手柄交互可用。远程联机与纯本地分屏协调退出仍为未实测预览；混合远程与分屏只提醒。

默认每天 60 分钟，按北京时间（Asia/Shanghai）00:00 重置。进入存档后，菜单、暂停和后台都会累计现实会话时间；标题和休息界面不计时。本机分屏只计一份时间。剩余 10 分钟提醒，额度用完后允许完成当前游戏日；单人确认原版实际保存完成并等待原生结算与过夜同步结束后，在新一天显示休息界面，可主动返回标题，午夜自动解锁。重进或换存档不能刷新额度。

**0.1.6 保存观察修复预览保留已由用户确认的手柄操作，以及同版远程联机及纯本地分屏保存结算后的协调退出预览；房主满额会结束房间。远程每台一名玩家，纯本地分屏全屏就绪后主屏统一回标题，混合模式仅提醒。** 保存实现或结算边界无法核实时也只提醒，保留原生错误恢复。0.1.5 实测发现保存观察漏判，0.1.6 修复已通过单人保存与休息流程的人工验证；多人同步尚未实测，不能宣称多人实测已通过。计时文件位于系统用户应用数据目录的 `StardewValley/TimeEase/usage.json`，不在游戏存档内；配置与故障处理见 [TimeEase 说明](mods/TimeEase/README.md)。

## 配置

- `Mods/.farm-ease-menu.json`：唯一一份统一菜单设置，保存菜单快捷键、重复等待/间隔、内容宽度。卸载某个功能不会丢失这些设置。
- `Mods/TravelEase/config.json`：回家快捷键和长按时间，以及一键睡觉的手柄长按开关与时长。
- `Mods/FishingEase/config.json`：钓鱼辅助参数，保持原配置结构。默认绿条 ×1.2、宽限 300ms、稳定恢复 500ms、进度损失 ×0.6、底部反弹 ×0.25。
- `Mods/StorageEase/config.json`：随行模式、制作自动取材默认开，烹饪自动取材默认关；可配置菜单键长按开箱的开关、时长与键盘开箱键（默认 F9，None 禁用）。
- `Mods/SignEase/config.json`：`Enabled=true` 默认自动展示；多人时由房主统一控制。
- `Mods/HorseEase/config.json`：`KeyboardSummonButton=F10`，`ControllerSummonButton=None`；可设专用手柄键，`None` 禁用对应快捷键，菜单入口仍可使用。避免与其他快捷键重复。
- `Mods/RidingEase/config.json`：`DisableHorseRumble=true` 默认关闭马蹄震动；本机分屏共用设置。
- `Mods/TimeEase/config.json`：每日分钟数、时区、重置时刻、提前提醒。自带设置页可从标题右上角/F11、农场随心→适时而归、休息界面的设置/今日加时进入。每日限额保存后立即重算；重置时刻返回标题后生效；今日加时独立持久化，不清零已用量。
- 田园巧整没有额外的功能配置；菜单和整理光标共用导航设置。

菜单「刷新配置」或 F6 重新读取全部设置。钓鱼参数在下一条鱼生效，避免当前绿色条突然变化。

原有控制台命令 `farmease` 现在打开统一菜单，`farmease status` 显示菜单提供者、功能分类与当前存档路径。
`gardenease` 直接进入整理模式；`travelease` 打开对应分类，`storageease` 快捷打开上次的箱子，`fishingease` 保留钓鱼状态和预设命令；`horseease` 呼唤自己的马。

## 构建与安装

目标环境：Stardew Valley 1.6.15、SMAPI 4.5.2。使用 .NET 8 SDK 构建，产物目标为 .NET 6。

```bash
./build.sh
./build.sh --install
```

可通过 `STARDEW_GAME_PATH` 指定包含游戏 DLL 的目录，默认 `/Applications/Stardew Valley.app/Contents/MacOS`。
可通过 `STARDEW_DOTNET` 指定 SDK 可执行文件；也支持 `.work/dotnet/dotnet`。

构建产出八个独立安装包、`dist/FarmEase-Collection.zip` 合集和 `dist/FarmEase-Collection-source.zip` 完整源码包。
安装器在游戏关闭后工作，将旧版 FarmEase 移到工作区 `.work/backups/installed-时间戳`，拆分迁移原有菜单与回家设置，保留钓鱼配置。安装失败会尝试恢复原目录。不会修改正式存档。
手动安装和卸载步骤见 `INSTALL.md`，各 Mod 的完整说明在对应 `mods/*/README.md`。

## 模块边界

每个 Mod 有自己的入口、manifest、程序集和独立功能代码。它们不互相引用项目，也不声明强制依赖。

`shared/FarmMenu` 是编译进各 Mod 的共享菜单源码：运行时在已安装的八个 Mod 中选择一个菜单提供者，通过 SMAPI API 注册功能分类与回调，只安装一份原生菜单补丁。
共享层只处理菜单、输入、设置和生命周期，不持有传送、作物搬移或钓鱼业务。菜单提供者停用后，下次启动由另一个已安装的 Mod 自动接管。

旧 FarmEase 的配置迁移只在安装器内处理。运行时不加载旧版，也不依赖旧项目目录。
