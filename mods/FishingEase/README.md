# 从容钓鱼 / Fishing Ease 0.3.0

为 Stardew Valley 1.6.15、SMAPI 4.5.2 制作的钓鱼辅助。保留按住上升、松开下降的追鱼玩法，允许更多修正错误的机会。鼠标、键盘和手柄沿用原版输入方式。

## 默认效果

- 绿色条：在原版等级、食物、鱼竿、鱼饵和浮漂计算完成后加长 20%（取整到像素）。
- 补救窗口：鱼离开绿色条时，有累计 300 毫秒的宽限，期间不增加或扣除捕获进度。
- 宽限恢复：连续框住鱼 500 毫秒后恢复完整宽限。短暂擦回绿色条不会刷新宽限。
- 失误惩罚：宽限用尽后，进度损失为原版的 60%。框住鱼时的捕获速度不变。
- 触底缓冲：底部反弹速度降到原版的 25%，顶部碰撞、正常加速度保持原版。

仍然需要操作，仍然可能跑鱼。鱼的移动方式、难度参数和捕获进度上涨速度不变。
保留训练竿、软木塞浮标、陷阱浮标、铅制浮标、祝福等原版效果，辅助在这些效果上叠加。
每次咬钩使用一份配置快照，避免调整配置时当前绿色条突然变化。

宽限只影响普通进度损失，不恢复完美捕获、不免除挑战鱼饵扣鱼或归零失败，也不取消原版鱼尺寸缩减。
寻宝、首条鱼教学、节日等特殊逻辑仍由原版决定；本 Mod 不对它们强行恢复进度。

## 安装

退出游戏，把安装包中的 `FishingEase` 文件夹放入 `Mods` 目录，通过 SMAPI 启动。
本机路径：`/Applications/Stardew Valley.app/Contents/MacOS/Mods/FishingEase`。
首次启动会生成 `config.json`。

## 调节难度

打开「农场随心 → 从容钓鱼」，选择关闭、轻度、默认或大幅辅助。当前预设会显示「当前」，选择后自动保存，从下一条鱼生效。
安装其他同系列 Mod 时共用同一个芽苗标签；只安装本 Mod 也能独立提供菜单，不需要额外核心。L3 / F7 直达，LT / RT 切页。
菜单按键和导航设置在 `Mods/.farm-ease-menu.json`，辅助参数仍独立保存在本 Mod 的 `config.json`。

在 SMAPI 控制台输入一个预设命令，从下一条鱼生效：

```text
fishingease preset light
fishingease preset normal
fishingease preset strong
fishingease preset off
```

| 预设 | 绿条长度 | 宽限 | 进度损失 | 触底反弹 |
| --- | --- | --- | --- | --- |
| light 轻度 | ×1.1 | 150ms | ×0.8 | ×0.5 |
| normal 默认 | ×1.2 | 300ms | ×0.6 | ×0.25 |
| strong 大幅 | ×1.35 | 500ms | ×0.35 | ×0.1 |
| off 关闭 | 原版 | 原版 | 原版 | 原版 |

预设会保存整套参数，并将宽限恢复时间设为 500ms。各项功能可以单独通过 `config.json` 调节：

| 配置 | 默认值 | 范围与关闭方式 |
| --- | --- | --- |
| `Enabled` | `true` | `false` 关闭全部辅助 |
| `BarSizeMultiplier` | `1.2` | 1–1.5；1 关闭加长 |
| `GracePeriodMilliseconds` | `300` | 0–1000；0 关闭宽限 |
| `GraceResetMilliseconds` | `500` | 100–2000；重新框住鱼多久后恢复宽限 |
| `ProgressLossMultiplier` | `0.6` | 0.1–1；1 使用原版扣减速度 |
| `BottomBounceMultiplier` | `0.25` | 0–1；1 使用原版反弹，0 无触底反弹 |

修改文件后在控制台运行 `fishingease reload`，无需重启。从下一条鱼生效。
`fishingease status` 显示实际配置、补丁状态；在钓鱼过程中也可显示绿色条和宽限剩余状态，便于定位问题。
非法 JSON 不会覆盖文件，运行中保留上一次有效配置；首次读取失败则采用默认值。越界参数会在内存中限制并记录警告。
也可以通过统一菜单的「刷新配置」或 F6 一起刷新各功能及菜单设置。

## 兼容与卸载

与随心往返、田园巧整独立安装和启停。不会写入新的存档对象，也不会修改游戏 DLL；退出游戏后移走本 Mod 文件夹即可恢复原版钓鱼。
这是针对 1.6.15 的 Harmony 补丁，其他版本和其他钓鱼补丁需要重新验证；不要同时安装修改相同钓鱼逻辑的 Mod，除非已经验证兼容。
如果找不到预期的钓鱼代码位置，会记录错误并撤回本 Mod 的全部补丁，避免只生效一部分。
支持联机与本地分屏。只需想获得辅助的玩家安装，不要求房主安装，不改变其他电脑玩家的辅助设置。状态按每个钓鱼小游戏实例分别保存。
分屏各玩家当前的辅助设置独立，改变自己的预设不会改变另一位已初始化玩家的辅助强度，也不会改变正在进行的鱼。config.json 仍是本机共享的下次启动默认值；新加入的分屏玩家从该默认值初始化。
多人及分屏路径已实现并通过编译，但按用户要求未启动游戏验证。

## 源码结构

- `ModConfig.cs`：独立参数、范围限制、难度预设。
- `FishingSession.cs`：每条鱼的配置快照、绿色条长度、宽限消耗和恢复。
- `FishingPatches.cs`：构造后调整长度，在原版更新的准确位置插入宽限、扣减倍率和底部反弹调整。
- `ModEntry.cs`：SMAPI 生命周期、补丁安装与失败回退、配置命令。

没有复制整个原版更新方法。进度损失在原版判断跑鱼之前调整，不会先播放跑鱼再事后补回进度。
