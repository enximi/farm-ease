# 随取随用 / Storage Ease 1.3.0

独立仓储便利 Mod，目标 Stardew Valley 1.6.15 + SMAPI 4.5.2，接入「农场随心」统一菜单。默认随行模式：所有玩家在各地访问所有支持的箱子，原版制作页自动取材。不会扩大背包，不会自动存入采集物。

## 使用

1. 短按 L3 松开或按 F7 打开「农场随心」，选择「随取随用」直接打开上次使用的箱子；不再经过功能页和“打开仓储”。**长按 L3 约 0.5 秒 / 按 F9** 可从游戏直接开箱，长按触发后松开不会再弹菜单。L3 跟随共享配置中的 MenuButton；未安装本 Mod 或关闭长按开箱时，菜单键仍在按下时打开普通菜单。
2. 上次箱子按玩家记录 ID，随存档保存，搬动箱子后仍能找到；只记录标识，不复制库存。首次使用、箱子已拆除或关闭远程时显示箱子列表。被占用或开箱失败时提示并回到列表，不强制抢锁。
3. 原版箱子界面上方有「全部箱子」，鼠标点击或按 **L3 / F7** 进入列表。搜索框按箱名、地点或箱内物品过滤；F 聚焦搜索，手柄 Y 打开文字输入。上下选箱，左右选择底部操作，Enter / A 执行；滚轮、PageUp/PageDown、LB/RB 翻页。
4. 所有玩家都可切换箱子的“远程开关”“取材开关”，或改名（最多 32 字）。列表右上角「设置」（Menu / Start 或 F6）调整随行/舒适模式、制作/烹饪自动取材与长按开箱开关。列表约 5 秒刷新，也可手动刷新。
5. 退出箱子或列表：快捷键/手动开箱路径直接回到游戏；从统一菜单进入则返回「农场随心」首页。等待开箱时可按 B / Esc 取消；查看全部箱子前要先放下手中的物品。

快捷键只在角色可自由操作时触发，不接管其他菜单或文字输入。长按状态按分屏区分，失焦、换地图、返回标题、过夜或刷新菜单配置时清除。F9 可在 `config.json` 的 `KeyboardOpenButton` 改键或设为 `None` 禁用；`EnableMenuHold` 控制长按开箱，`MenuHoldMilliseconds` 默认 500，允许 250–2000 毫秒。

## 箱子标签切换

走到箱子旁手动打开，或从仓储列表打开箱子后，原版箱子界面上方显示一排标签和「全部箱子」入口。当前箱子高亮；箱子较多时只显示附近的几个标签，切换时自动滚动。

- **手柄 LT / RT**：上一箱 / 下一箱，与统一菜单切换标签的按键一致；首尾循环。
- **键盘 PageUp / PageDown**：上一箱 / 下一箱；上下左右仍用来选择物品。
- **鼠标**：点击箱名或两侧箭头；悬停显示完整箱名、地点、坐标和总箱数。长箱名在标签上省略显示。
- 标签使用原版箱子顶部空白区域，不移动箱子与背包格子；LB / RB 仍执行原版箱子中的导航操作。
- 其他标签包含全部开启远程访问的箱子，沿用随行/舒适模式限制。手动打开的关闭远程访问的箱子仍能正常操作，但切到其他箱子后不能从标签远程返回。
- 鼠标手中有物品时先放下才能切换。等待同步或使用锁期间不会重复发起切换；仍可取消关闭或继续操作原箱子，原箱子状态变化会取消待执行切换。
- 切换成功前保留原箱子及其锁；目标被占用、移走或关闭远程访问时停留原箱子并提示。切换成功后释放原箱子的锁。祝尼魔箱子的不同入口继续使用同一份原生库存与使用锁。

## 默认与范围

- **随行模式（默认）**：在正常可操作的地图使用；活动、过场、昏迷等状态不可用。
- **舒适模式**：仅当玩家在农场室外或农舍/小屋时使用。限制玩家所在地点，材料箱仍可位于其他已登记的固定地图。
- **制作自动取材（默认开）**：使用普通制作页或原版工作台，先扣背包，再用工作台已有材料，最后使用允许取材的箱子。
- **烹饪自动取材（默认关）**：开启后扩展原版厨房/野炊工具的食材来源及可用调味料；不添加随地烹饪入口。不改变原版冰箱取材规则。

普通木箱、石箱、巨型箱子和祝尼魔箱子统一供所有玩家使用，默认“远程开、取材开”。不按放置者或箱主筛选列表、标签、取放、制作材料和设置操作。所有玩家都可改名及调整远程/取材开关，开关对全体玩家一致生效；有人正在使用箱子时暂不允许更改设置。祝尼魔箱子仍使用原有库存，多个入口不会重复计算材料。

从旧版升级时，旧的 shared 标记不再读取，也不再写入；此前设置为私人的箱子自动向所有玩家开放，无需重新放置或逐箱修改。不改写原版箱主字段或库存。远程和取材开关保留此前的选择，关闭时对所有玩家一视同仁。

不包含 NPC/奖励箱、开局礼物、冰箱、迷你出货箱、机器附件库存、自动装料箱及第三方自定义 Chest 子类。原版冰箱仍通过厨房正常使用。箱子位置覆盖固定地图及建筑内部，不纳入临时生成的矿洞/火山楼层。列表汇总所有支持的箱子；所有开启取材的箱内材料均可供玩家制作使用。

## 制作与游戏性

只扩展原版 CraftingPage，不改写玩家背包，也不会将远程物品用于自动送礼、交任务、献祭、出售或机器投料。配方学习条件、产量、品质、成就与制作统计沿用原版。

箱内材料显示在原版配方可制作判定与提示中。实际制作前先取得本次需要箱子的原生 NetMutex，再检查当前配方、材料、取材开关与背包容量，调用原版消耗逻辑，成品放入背包。没有空位或可合并位置时拒绝制作，即使这次消耗材料可能腾出位置，也需先手动腾出空间。

等待锁期间重复同一配方的点击会合并为最多 25 次，取得锁后逐次检查材料与空间；只使用本次已锁定的材料箱，不足即停止，可再次点击继续。不同配方需等前一次完成。使用中的箱子不参与远程材料预览。不会为了浏览制作页长期锁住所有箱子。

## 多人

房主和使用本功能的玩家需安装相同版本 StorageEase 1.3.0。不使用本功能的玩家不必安装。分屏配置与当前操作按屏幕区分；同机配置文件作为下次启动的共同默认。

房主向所有使用者发布相同范围的箱子目录，核对箱子位置、功能开关及使用锁后批准访问会话。客户端订阅相关原版地图网络字段，初始状态与远程增量通过同一 SMAPI 通道同步；物品仍存放在原箱子，不复制到临时库存，也不转换成新的存档对象。箱子元数据使用 ID、名字与远程/取材两个开关；玩家元数据额外保存上次箱子的 ID。

远程使用锁会按在线玩家维持，避免玩家不在箱子地图时被原版提前释放。手动与远程开箱统一跟踪使用锁，关闭时明确释放；取放或整理物品导致同一箱子界面重建时继续保留锁，切箱时等目标成功打开后再释放旧箱。关闭后下一帧仍会复核；房主的远程保活只作用于未关闭会话对应玩家的锁，旧会话不保活后来使用者的锁。

打开只锁该箱子，制作只锁实际使用的箱子；支持多人使用不同箱子。遇到同箱争用会提示稍后重试。关闭、取消、换地图、保存会释放自己取得的锁；延迟到达的锁授权会自动释放。服务器保留正在使用的锁，不因一个超时消息强行抢锁，断线后由原生机制释放。与田园巧整共用同一箱子锁，因此远程使用期间不能被整理搬走。

## 配置与安装

`Mods/StorageEase/config.json`：`Anywhere=true`、`CraftFromStorage=true`、`CookFromStorage=false`。在箱子列表的设置页切换后自动保存；统一菜单的 F6 可重读配置。`storageease` 直接打开上次的箱子。

本版需房主和使用者统一更新至 1.3.0。同机已安装的其他系列 Mod 也建议更新到本次配套版本，以启用共享菜单长按入口。

独立安装即可提供统一入口；与其他系列 Mod 同装时自动汇总，不需要额外核心 Mod。退出游戏后移走 StorageEase 即可停用，原箱子物品照常可用，已保存的少量箱子元数据不会影响原版取放。

本次仅进行源码核对、Release 编译与安装校验，按要求未启动游戏、未编写测试。跨玩家开箱/设置/制作取材、旧箱子标记兼容、快捷开箱与返回路径、箱子标签布局与切换、关闭解锁的多人运行效果、远程箱子界面、搜索/手柄操作、合成扣料、跨地图同步、断线及分屏尚未实机验证。替换原版制作界面或直接操作库存的第三方 Mod 不在本次兼容性验证范围内。

长按菜单键修复：不把 SMAPI 屏蔽按键后产生的 Released 事件当成真正松手，改为逐帧结合 IsDown / IsSuppressed 判断；短按在真正松开后打开菜单，长按达到时长只触发一次开箱。
