# 随取随用 / Storage Ease 1.0.0

独立仓储便利 Mod，目标 Stardew Valley 1.6.15 + SMAPI 4.5.2，接入「农场随心」统一菜单。默认随行模式：各地访问自己的箱子及他人主动共享的箱子，原版制作页自动取材。不会扩大背包，不会自动存入采集物。

## 使用

1. F7 / L3 打开「农场随心 → 随取随用 → 打开仓储」。列表显示箱名、地图与坐标、远程/取材/共享开关。
2. 搜索框可按箱名、地点或箱内物品名称过滤。鼠标点击输入；F 聚焦搜索，手柄 Y 打开游戏文字输入。上下选箱，左右选择底部操作，Enter / A 执行，Esc / B 返回；滚轮和 PageUp/PageDown、LB/RB 翻页。
3. 选择“打开”，取得原生使用锁后打开原版箱子界面，正常取放、整理，背包容量照常限制。箱子正被别人使用、正在搬动、已被移走或权限改变时会拒绝打开，请刷新后重试。
4. 自己的箱子可分别切换“远程开关”“取材开关”“共享开关”，或改名（最多 32 字）。设置随原箱子保存，田园巧整搬动箱子后保留；列表约 5 秒刷新，也可手动刷新。

## 默认与范围

- **随行模式（默认）**：在正常可操作的地图使用；活动、过场、昏迷等状态不可用。
- **舒适模式**：仅当玩家在农场室外或农舍/小屋时使用。限制玩家所在地点，材料箱仍可位于其他已登记的固定地图。
- **制作自动取材（默认开）**：使用普通制作页或原版工作台，先扣背包，再用工作台已有材料，最后使用允许取材的箱子。
- **烹饪自动取材（默认关）**：开启后扩展原版厨房/野炊工具的食材来源及可用调味料；不添加随地烹饪入口。不改变原版冰箱取材规则。

自己的普通木箱、石箱、巨型箱子和祝尼魔箱子默认“远程开、取材开、共享关”。原版 owner 字段识别主人；历史上没有主人记录（owner=0）的箱子归房主管理。分享只开放本 Mod 的远程访问/取材，不能把原版物理箱子变成有密码的私人箱子。祝尼魔箱子仍是游戏原有共享库存，多个入口不会重复计算材料。

不包含 NPC/奖励箱、开局礼物、冰箱、迷你出货箱、机器附件库存、自动装料箱及第三方自定义 Chest 子类。原版冰箱仍通过厨房正常使用。箱子位置覆盖固定地图及建筑内部，不纳入临时生成的矿洞/火山楼层。菜单只列出自己的及主动共享的箱子，不默认纳入其他玩家的私人材料。

## 制作与游戏性

只扩展原版 CraftingPage，不改写玩家背包，也不会将远程物品用于自动送礼、交任务、献祭、出售或机器投料。配方学习条件、产量、品质、成就与制作统计沿用原版。

箱内材料显示在原版配方可制作判定与提示中。实际制作前先取得本次需要箱子的原生 NetMutex，再检查当前配方、材料、权限与背包容量，调用原版消耗逻辑，成品放入背包。没有空位或可合并位置时拒绝制作，即使这次消耗材料可能腾出位置，也需先手动腾出空间。

等待锁期间重复同一配方的点击会合并为最多 25 次，取得锁后逐次检查材料与空间；只使用本次已锁定的材料箱，不足即停止，可再次点击继续。不同配方需等前一次完成。使用中的箱子不参与远程材料预览。不会为了浏览制作页长期锁住所有箱子。

## 多人

房主和使用本功能的玩家需安装相同版本 StorageEase 1.0.0。不使用本功能的玩家不必安装。分屏配置与当前操作按屏幕区分；同机配置文件作为下次启动的共同默认。

房主发布箱子目录，核对主人/共享权限并批准访问会话。客户端订阅相关原版地图网络字段，初始状态与远程增量通过同一 SMAPI 通道同步；物品仍存放在原箱子，不复制到临时库存，也不转换成新的存档对象。箱子元数据只保存 ID、名字与三个开关。

远程使用锁会按在线玩家维持，避免玩家不在箱子地图时被原版提前释放。打开只锁该箱子，制作只锁实际使用的箱子；支持多人使用不同箱子。遇到同箱争用会提示稍后重试。关闭、取消、换地图、保存会释放自己取得的锁；延迟到达的锁授权会自动释放。服务器保留正在使用的锁，不因一个超时消息强行抢锁，断线后由原生机制释放。与田园巧整共用同一箱子锁，因此远程使用期间不能被整理搬走。

## 配置与安装

`Mods/StorageEase/config.json`：`Anywhere=true`、`CraftFromStorage=true`、`CookFromStorage=false`。在统一菜单切换自动保存；F6 可重读配置。`storageease` 打开随取随用分类。

独立安装即可提供统一入口；与其他系列 Mod 同装时自动汇总，不需要额外核心 Mod。退出游戏后移走 StorageEase 即可停用，原箱子物品照常可用，已保存的少量箱子元数据不会影响原版取放。

本次仅进行源码核对、Release 编译、打包与安装校验，按要求未启动游戏、未编写测试。远程箱子界面、搜索/手柄操作、合成扣料、跨地图同步、断线及分屏尚未实机验证。替换原版制作界面或直接操作库存的第三方 Mod 不在本次兼容性验证范围内。
