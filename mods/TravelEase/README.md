# 随心往返 / Travel Ease 1.3.0

独立的快捷传送与回床睡觉 Mod，目标环境 Stardew Valley 1.6.15 + SMAPI 4.5.2。

- 「农场随心 → 随心往返」：回家、选择目的地、返回上个位置、一键睡觉。
- 目的地按「农场周边、小镇、野外、远方」分组，共 16 个落点；自动检查安全落脚点。
- 矿洞目的地为普通矿洞入口大厅（电梯与梯子所在处），自动避开落点附近障碍；电梯楼层仍按原版进度解锁。大厅也可作为「返回上个位置」的返回点，地下随机矿层不记录为返回点。
- R3 / F8 长按 0.7 秒回家；松开取消，保留进度提示。
- 不消耗金钱或物品。返回位置在过夜、退出存档时清空。
- 支持单人、联机和本地分屏；对话、小游戏、过场、使用工具、骑马、游泳时不传送。特殊活动期间部分目的地关闭。
- 联机只需使用传送的玩家安装；通过游戏原生传送同步位置。回家前往该玩家自己的住宅门外，农场帮手回到自己的小屋。落脚点避开其他玩家。
- 分屏各玩家的长按进度与返回位置独立。按键配置仍共用本机 config.json。

## 传送目的地

| 分组 | 目的地 |
| --- | --- |
| 农场周边 | 家门口、巴士站、森林、旅行货车附近、法师塔门口 |
| 小镇 | 小镇、铁匠铺 / 博物馆、海滩、鱼店码头 |
| 野外 | 山上、矿洞、铁路 / 温泉、采石场、秘密森林 |
| 远方 | 沙漠、姜岛码头 |

旅行货车附近落在车外；货车仍按原版日期与时间营业。法师塔、铁匠铺、博物馆和鱼店均落在建筑外，不跳过门锁、剧情或营业时间。

未解锁的目的地显示灰色与开放条件，条件满足后即可选择：

- 铁路 / 温泉：第一年夏季地震后（游戏第 31 天）开放。
- 采石场：社区中心工艺室或 Joja 修桥真正完成后开放，不把待次日完成的修复当作已完成。
- 秘密森林：森林入口的大木头清除后开放，不按斧头等级猜测。
- 沙漠：巴士修复后开放，沿用原版沙漠可达性判断。
- 姜岛码头：船修复完成，并且当前玩家已正常登岛至少一次后开放。落点仅在南部码头，不解锁岛内其他区域。

全部传送沿用免费规则，不消耗金钱或物品；解锁后的沙漠与姜岛传送也不收车船票。菜单选择、实际传送和返回旧位置均检查开放条件。新增地图支持记录返回点；随机地下矿层仍不记录。

安全落点避开地图外、无地板、水面、障碍、其他玩家、出口与踩踏触发格，以及当日旅行货车的占地区域。仍沿用特殊活动期间只开放回家的限制。目标区域被第三方地图 Mod 大幅改动时，固定落点可能不再合适，需要单独适配。

## 一键睡觉

「农场随心」首页与「随心往返」页面均有「一键睡觉」。点击后回到当前玩家自己住宅中的床位，直接确认睡觉，不需要再点一次“是”。没有床时提示先放好床。

手柄 View / Back 短按松开时打开原版任务日志，长按默认 1.2 秒触发一键睡觉，长按期间显示进度。未满时松开不会睡觉；触发后继续按住不会重复执行。仅在自由操作时接管，菜单、对话和事件中保留原键作用；失焦、传送或次日会清理长按状态。若自定义菜单或回家快捷键占用了 View / Back，则原快捷键优先，睡觉仍可从菜单进入。

通过原版 Sleep_Yes 入口执行睡觉：保留正常的每日结算、升级、夜间事件、存档和体力恢复规则，不修改时间或直接写入存档。多人和分屏只让当前玩家进入原版等待界面，仍需其他玩家准备就绪，可取消等待；取消后留在自己的床边。只需使用者安装 TravelEase。

等待传送和淡入完成后才执行；若入屋触发事件、角色离开床位、床被移动/拆除、倒下或超过 30 秒，取消本次自动睡觉。对话、活动、小游戏、骑马、游泳、使用工具或坐着时不能发起；不会自动确认其他对话。等待期间不接受重复回床或传送请求。返回位置仍在次日清空。

独立安装也会提供「农场随心」芽苗菜单；安装其他同系列 Mod 后自动汇总到同一入口。L3 / F7 直达，LT / RT 切换标签。

`config.json` 中可设置 `HomeButton`、`KeyboardHomeButton`、`HomeHoldMilliseconds`。`EnableSleepShortcut` 默认 true，设为 false 可关闭 View / Back 长按睡觉；`SleepHoldMilliseconds` 默认 1200，允许 1000–3000 毫秒。已有配置缺少这两个字段时使用默认值，不需修改旧配置。共享菜单按键和重复速度保存在 `Mods/.farm-ease-menu.json`。
修改后在统一菜单选择「刷新配置」，或输入 `travelease reload`（仅刷新传送配置）。
`travelease` 打开传送页面，`travelease home` 回家，`travelease sleep` 一键睡觉；`farmease` 打开统一菜单。

可独立停用，不依赖田园巧整或从容钓鱼，不写入自定义存档对象。
多人及分屏路径已实现并通过编译，但按用户要求未启动游戏验证。
从旧版 FarmEase 升级必须移走旧 FarmEase，推荐使用工作区的 `./build.sh --install` 自动迁移并备份。
