# 田园巧整 / Garden Ease 1.4.1

独立的农场整理 Mod，目标环境 Stardew Valley 1.6.15 + SMAPI 4.5.2。

在农场室外打开「农场随心」，选择「田园巧整」直接进入整理模式。单人整理时暂停时间；多人整理时不暂停世界。

1. 方向键 / WASD / 十字键 / 左摇杆选择一格。
2. A / Enter / 左键选中，再移到目标格确认：绿色框表示可以搬入，金色框表示可以交换，红色框表示不能放置。
3. B / Esc / 右键取消选中；没有选中时直接返回「农场随心」主菜单；等待房主确认时也可直接返回。
4. X / Z 撤销上一步；交换可一步恢复双方。退出整理后撤销记录清空。

## 支持对象与状态

| 对象 | 搬移时保留 | 范围预览 |
| --- | --- | --- |
| 普通耕地、作物、棚架作物 | 生长进度、浇水、肥料及附属数据 | 无 |
| 普通树木、果树，从种子/树苗到成树及其树桩 | 树种、生长阶段、树龄、肥料、苔藓、树上果实、受雷击状态及附属数据 | 当前生长阶段的树形预览 |
| 树上采集器、重型采集器 | 随原树整体移动，保留产物、加工进度和原树的关联 | 随树预览 |
| 洒水器 | 原物体及增压喷头、施肥器等附件 | 蓝色，随目标格移动，含喷头加成 |
| 普通、珍奇与豪华稻草人 | 原物体、驱赶次数及装饰状态 | 金色，使用该稻草人的实际保护半径 |
| 道路、地板 | 地板种类及附属数据，更新相邻连接 | 无 |
| 围栏、大门 | 材质、耐久、开关状态及附件 | 无 |
| 普通/石制箱子、巨型箱子、祝尼魔箱子 | 内部物品、颜色、名称、容量和共享库存关系 | 无 |
| 迷你出货箱、自动装料箱 | 原有库存和状态 | 无 |
| 普通地面加工机器，如熔炉、酿造桶、罐头瓶 | 投入物/产出物、剩余加工时间、就绪状态及附属数据 | 无 |

范围显示的是拟放置位置的覆盖区域；不合法的位置显示红色。洒水器范围通过游戏的 GetSprinklerTiles 计算，排除禁止洒水的地图格；稻草人使用游戏驱鸦逻辑的距离判断，豪华稻草人自然显示更大范围。交换时也显示另一件设施换回原位置后的范围，颜色较淡。搬移不会立即浇水，也不会启动、完成或重置加工。

## 分层与交换

同一格上有物体和道路时优先选中物体；只移动物体，下方的道路或空耕地留在原处。要移动被遮住的道路，需要先搬开上面的物体。

空位置可直接搬入。耕地/作物之间、树木/果树之间、道路/地板之间、上述支持的物体之间可互相交换；不同类别不能互换。各自的内容和状态随各自对象移动，双方都要符合目标格的放置规则。

树木选择树干底部所在格，采集器和树作为整体选中、搬移和撤销，不留在旧位置，也不重新计算产物。普通树与果树可以互换，采集器始终跟随原树。选择后若有人拆装采集器或替换树木，会拒绝搬移；正在倒下或销毁的树不能整理。成熟果树保留已有果实与树龄，不重新等待 28 天。

树木不能覆盖耕地、道路或其他设施，需先搬开。放置遵守地图禁种区域与障碍限制；果树需放到可种植的泥土/草地。果树与任何其他树之间至少隔两格，普通树也不能搬入果树的两格间距内。未成熟果树周围八格不能有道路、作物、设施或大型地形，草与无作物耕地允许保留；成熟果树不再要求这八格留空。检查按搬移/交换后的布局计算，撤销也会重新检查。普通树之间不额外限制间距，过密时仍按原版规则影响幼树生长。

物体可放在道路或无作物的普通耕地上，不覆盖作物、树木、建筑或动物。整理道路和耕地时，目标格上的物体仍会阻止放置。挡路的作物、箱子、机器等不能放到角色脚下；普通作物与道路不受此限制。正在使用的箱子及附属容器不能搬移。
大门搬移后会遵循游戏对新邻接关系的规则，不满足连接条件时游戏可能自动关门。

所有操作直接移动原有对象，不走敲掉、回收、重新制作或重新放置的流程。撤销前核对两边仍是原有对象，并重新检查碰撞；位置已改变时拒绝覆盖。异常时尝试恢复双方，并记录错误。

## 镜头与范围

进入整理时保留当前视角。选格在中央区域移动时画面固定，接近边缘才平滑滚动，不再每格居中。
横向固定区域为画面中央约 60%；纵向避开上下操作面板，并按游戏缩放、界面缩放换算边界。
滚动约 0.2 秒接近目标，光标退回固定区域后停止跟随。到地图边界时镜头停止。
浏览、搬移和撤销共用相同跟随方式；退出整理后恢复原版角色视角。

支持单人、联机和本地分屏的农场室外，不支持室内、批量整理、巨型作物、大树桩/大木头等资源块、灌木、花盆、建筑、家具、蟹笼及使用特殊自定义类的 Mod 对象。采集器只随普通树整体移动，不单独挪到另一棵树上。机器支持使用原版 Object 和机器数据的地面加工设备，不包含要求特殊地形或房间的特殊子类设备。数据包添加的同类普通对象可被识别，但第三方行为兼容性未实机验证。

## 多人整理

- 房主和参与整理的玩家须安装相同版本的田园巧整（本版 1.4.1）；不参与整理的玩家不必安装。缺少房主 Mod 或版本不一致时显示提示。
- 房主、客机和本地分屏玩家可以同时进入整理，各自选择对象、移动光标和撤销。世界时间继续流逝。退出、离开农场、断线或无心跳 30 秒后只释放该玩家的会话；过夜清空全部会话。
- 选中的源格暂时保留给该玩家，包含该格地面与物体两层；其他整理者不能选中、放入、交换或撤销到这一格。放下、取消或离开会话即释放。目标光标所在格不提前占用，浏览不会占住土地；实际提交时由房主按顺序完整执行。
- 两人同时向同一空格搬入时，先成功的一方生效，另一方收到位置变化提示，需等同步后重新确认或选择别处。两人分别选中两格后不能直接互换，须先由一人取消选中，再由另一人发起交换。
- 客户端仅预览和发送请求，房主检查玩家身份、所在地图、原对象和目标格是否变化、角色与动物占用、箱子使用状态，然后执行搬移或交换。箱子及附属容器使用游戏原生互斥锁；原生网络字段同步最终布局、物品和加工状态。
- 等待房主响应时不能重复确认。请求携带会话和顺序号，重发不会重复执行同一次操作；15 秒无响应关闭整理，提示先检查现场。等待中可取消退出。
- 其他玩家仍可耕种、收获、取放物品、使用机器；格子保留只协调本 Mod 的整理，不锁住正常游戏操作。目标格改变时拒绝本次放置并要求等同步后重新确认；容器正在使用时拒绝移动。
- 每个人只撤销自己的操作。另一名整理者后来改动过某格时，会使涉及该格的旧撤销记录失效，即使物体之后又被搬回也不会恢复旧记录；不相关的撤销记录保留。撤销还会检查两格是否被别人选中。撤销只恢复布局，不倒退已经发生的收获、库存变动或加工时间。可撤销数量在下次操作或约 5 秒的心跳状态更新时刷新。
- 多人及分屏路径已实现并通过编译，但按用户要求未启动游戏验证；高延迟、断线重连和第三方自动化 Mod 的联动仍需实机确认。

## 入口与安装

独立安装也会提供「农场随心」芽苗菜单；安装其他同系列 Mod 后自动汇总到同一入口。L3 / F7 直达，LT / RT 切换标签。
菜单和整理光标的长按重复设置共用 `Mods/.farm-ease-menu.json`。默认等待 250ms，然后每 70ms 移动一项。
修改后在菜单「刷新配置」或按 F6。`gardenease` 直接进入整理模式，`farmease` 打开统一菜单。

无需传送或钓鱼 Mod，也不需要额外核心 Mod。关闭游戏后移走本 Mod 即可停用；已经保存的布局不会自动恢复。
从旧版 FarmEase 升级必须移走旧 FarmEase，推荐使用工作区的 `./build.sh --install` 自动迁移并备份。
