# 一目了然 / Sign Ease 0.1.1

独立 SMAPI Mod，让箱子正后方的物品牌自动展示箱内第一个物品。目标 Stardew Valley 1.6.15 + SMAPI 4.5.2；无需安装随取随用或其他系列 Mod，可接入「农场随心」统一菜单。

## 摆放

在同一张地图中，将告示牌放在箱子**正上方、紧挨着的一格**（同一列）：

```text
[ 告示牌 ]  (x, y - 1)
[  箱子  ]  (x, y)
```

读取箱内按格子顺序排列的第一个非空、数量大于零的物品。取走首件、换入其他物品或整理箱子后，牌面自动跟着变化；箱子清空时，牌面图标也清空。不会排序、搬运或消耗箱内物品，也不占用背包格子。

默认自动开启，每 30 个游戏更新帧检查一次，通常约半秒。箱子正在取放、合成或搬移时，等待原生使用锁释放及搬移结束后再更新。没有长期开箱占锁的情况下，其他玩家只查看箱子不影响展示。

## 支持范围

- 原版物品牌：木牌、石牌、金色告示牌。文字告示牌、地图装饰和第三方自定义 Sign 子类不接管。
- 原版玩家箱子：普通木箱、石箱、巨型箱子、祝尼魔箱子。多个祝尼魔箱入口会显示同一份共享库存的首件物品。
- 固定地图及建筑内部均可使用；不包含临时生成的矿洞/火山楼层。
- 不包含冰箱、奖励/礼物箱、迷你出货箱、自动装料箱、机器附件或第三方自定义 Chest 子类。

匹配的告示牌会自动覆盖手动设置的图案。移走箱子或牌子、让两者不再上下相邻，或者关闭自动展示后，牌子保留最后的图案并恢复普通手动用途；不会修改其他未匹配的告示牌。用「田园巧整」整组移动后仍保持上下相邻，会继续跟随当前箱子更新。

## 设置和多人

「农场随心 → 一目了然 → 自动展示」可以开启或关闭，设置自动保存到 `Mods/SignEase/config.json` 的 `Enabled` 字段，默认 `true`。多人时只允许房主调整；它控制整个存档世界的自动更新，不按玩家分别设置。统一菜单的 F6 / 刷新配置可重新读取配置。

**只需房主安装。** 房主根据箱子内容更新原版告示牌 `displayItem` / `displayType` 网络字段，其他玩家即使没有安装本 Mod，也能通过游戏原生同步看到图案。仅客户端安装不会修改牌面；本地分屏只由房主屏幕执行一次更新。

使用与原版手动设置告示牌相同的 `getOne()` 展示副本，保留物品自身的图标类型、颜色与相关元数据；展示副本仅用于牌面，没有发放物品的操作。检测展示内容未变化时避免重复写入牌面。保存期间暂停更新；普通告示牌字段按原版方式随存档保存。

## 安装与停用

退出游戏，把 `SignEase` 文件夹放进 `Mods`，通过 SMAPI 启动。若使用骑乘长按开箱，请同步更新同机已安装的系列 Mod。单独安装也能提供「农场随心」菜单；和其他系列 Mod 一起安装时使用同一个入口。

关闭游戏后移走 `SignEase` 即可停用。告示牌保留最后保存的图案，箱内物品仍在原箱子中，不需要迁移存档。运行时不会另建库存或引入自定义存档对象。
