# 闻哨而来 / Horse Ease 0.1.0

独立的坐骑召唤 Mod，目标环境 Stardew Valley 1.6.15 + SMAPI 4.5.2。加入现有「农场随心」统一菜单，也可单独安装使用。

## 使用

- 在室外打开「农场随心」，直接选择「闻哨而来」，或在正常游戏中按 F10。
- 呼唤自己已有的马，无需获得或携带马笛、不消耗物品。请先正常建好马厩、认领并命名自己的马。
- 沿用原版马笛的归属、室外和落脚空间检查；室内、狭窄位置或自己的马正被其他玩家骑用时会提示原因。马已在一格之内时不再搬动；自己已骑马时也不重复召唤。
- 召唤通过原版团队网络事件交给房主复核并搬运原马，保留马的身份、名字、帽子及原有状态，不生成新马。实际位置以房主处理时的角色位置为准；请求发出后若条件变化，可能被原版拒绝，可等同步后再次呼唤。
- 「已呼唤坐骑」表示已发出请求，不是网络成功回执。每个本地玩家至少间隔 1.5 秒再次发起，不自动重试；不会强行解锁或抢走正在使用的马。
- 活动、对话、其他菜单、过场、工具使用、上下马动画、休息或过夜期间不触发快捷键。

## 手柄与配置

手柄默认从 L3 打开的统一菜单选择「闻哨而来」，不额外占用现有按键。可编辑 `Mods/HorseEase/config.json`：

```json
{
  "KeyboardSummonButton": "F10",
  "ControllerSummonButton": "None"
}
```

使用 SMAPI 的 SButton 名称，自行设置不冲突的手柄键。`None` 禁用该快捷键，不禁用菜单入口。与统一菜单键相同时优先保留菜单，不接管其他菜单或文字输入。修改后重启游戏或在统一菜单按 F6 重新读取配置。

## 多人和卸载

只需想使用此功能的玩家安装，房主无需额外安装；使用原版马笛网络协议，联机和本机分屏按当前玩家发起。请求节流按分屏独立；本机快捷键配置共用。马的归属与能否被召唤仍由原版决定。

退出游戏后移除 `Mods/HorseEase` 即可；已有马、马厩和原版马笛不受影响。构建及安装已核对，未启动游戏验证实际召唤、联机或分屏效果。
