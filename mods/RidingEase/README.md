# 悠然骑行 / Riding Ease 0.1.1

独立的骑马震动开关 Mod，目标环境 Stardew Valley 1.6.15 + SMAPI 4.5.2。

安装后默认关闭骑马时马蹄落地引起的手柄震动，覆盖木地、石地和其他原版地面。马蹄声、骑行速度、动画及钓鱼、受伤等其他来源的震动沿用原版。

## 使用与配置

在「农场随心 → 悠然骑行」切换「关闭骑马震动」。开启表示屏蔽马蹄震动，关闭表示恢复原版震动。菜单沿用系列入口：L3 / F7，或原生菜单最右侧的芽苗标签；请先下马再打开系列菜单。

`Mods/RidingEase/config.json` 的 `DisableHorseRumble` 默认为 `true`。菜单修改自动保存；手动编辑后可通过统一菜单「刷新配置」或 F6 重读。游戏原本关闭总震动时，恢复骑马震动也不会强制开启总震动。

多人游戏只需想关闭震动的玩家在自己的电脑安装，不要求房主安装，不发送多人消息或修改存档。本地分屏安装一份，各屏马蹄震动均被屏蔽；开关是本机共用设置。

## 安装与兼容

游戏退出后，将 `RidingEase` 文件夹放入 `Mods`，通过 SMAPI 启动。可以单独安装，也可与现有农场随心系列共用菜单，不需要额外核心 Mod。若使用骑乘长按开箱，请同步更新同机已安装的系列 Mod。

只替换原版马蹄方法中的三处震动调用，保留原本的本屏骑手检查，不拦截全局震动方法。目标方法或调用数量不符时撤回功能补丁并记录 SMAPI 错误，菜单显示「未生效」。第三方自定义坐骑或自行发送震动的 Mod 不在覆盖范围；修改同一原版方法的 Mod 需单独确认兼容性。

关闭游戏后移走本 Mod 即可恢复原版行为，无需转换存档。Release 编译与安装核对情况见项目 `VERIFICATION.md`；未启动游戏验证手柄、联机或分屏实际效果。
